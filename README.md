# DCOMP320 – Stack-Based Expression Evaluator (Version 3: Term-Stack Method)

Reads mathematical expressions from `input.txt`, evaluates each using stacks, and writes the results to `output.txt`.

## Requirements
Python 3.8+ (standard library only).

## How to run
```
python stack_calculator.py                      # input.txt -> output.txt
python stack_calculator.py my_in.txt my_out.txt # custom file names
```

## Files
| File | Purpose |
|---|---|
| `stack_calculator.py` | Source code |
| `input.txt` | Sample input used for testing |
| `output.txt` | Output generated by the program |

## Input format
One expression per line; expressions are separated by a line of three or more dashes (`-----`). Supported: `+ - * /`, parentheses, decimals, unary minus, spaces.

```
3 + 5 * 2
-----
(8 / 4) + 7 * 2
-----
10 - (2 + 3) * 4
```

## Output format
Same layout as the input; each expression is replaced by its result and the same separators are kept.

```
13
-----
16
-----
-10
```

## How it works
- A **term stack** holds the numbers that will be added at the end. `*` and `/` are applied at once to the top term (so they bind tighter); `+` pushes a term and `-` pushes the negated term.
- A **bracket stack** saves the current state at `(`. At `)` the bracket's terms are summed and treated as one number.
- Example: `10 - (2 + 3) * 4` → terms `[10, -5]` → `*4` → `[10, -20]` → total `-10`.

## Assumptions and limitations
- Division is true division (`7 / 2 = 3.5`). Whole numbers print without `.0`; others up to 6 decimals.
- Invalid expressions produce `Error: <reason>` on that line (division by zero, mismatched parentheses, invalid expression/character); the program continues.
- Blank lines are ignored. A missing input file gives an error message.
- Exponents, functions and variables are not supported.
- The assignment sheet's sample output shows `17` for `(8 / 4) + 7 * 2`; the correct value is `2 + 14 = 16`, which this program outputs.
